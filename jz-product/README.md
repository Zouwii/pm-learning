# JZ Product：公司材料与 AI 辅助稿

## 目录定位

这里保存公司已有的 PRD、架构设计，以及 AI 辅助生成的 PRD、方案和拆解材料。

这层回答的是：

- 公司原本怎么定义产品；
- 已有 PRD、架构或 AI 辅助稿提出了什么目标、范围与约束；
- 有哪些事实线索可以供自己的项目分析查证。

它是参考材料区，不代表其中所有内容都已经由用户确认。关键事实必须回到公司材料、代码、实验或真实 Case 核验，也不在这里包装个人贡献或 interview 话术。

## 与 `projects/` 的边界

| `jz-product/` | `projects/` |
| --- | --- |
| 公司 PRD、架构和 AI 辅助稿 | 自己独立写的 PRD |
| 待核验的目标、范围和设计 | 自己确认后的判断与取舍 |
| 事实线索和参考方案 | 个人职责、行动和证据 |
| 供查证和对照 | 项目复盘与 interview 讲述 |

整理公司材料或保存 AI 辅助稿时修改本目录；形成自己的 PRD、项目判断和讲述时修改 `projects/`。
