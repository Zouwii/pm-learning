# PM Learning

这个仓库只做三件事：学习 PM、整理公司产品材料、沉淀项目讲述。

## 从哪里开始

- 日常 PM 学习：[00-开始学习](./00-开始学习.md)；
- 日常项目完善：[01-项目完善](./01-项目完善.md)。

```text
00-开始学习.md
       ↓
interview：回答和训练方法
       ↓
projects：需要讲项目时再看
       ↓
jz-product：需要查公司材料或 AI 辅助稿时再看
```

## 目录边界

### `interview/`：我怎么回答

只保存实际训练过的 QA 和回答方法：

- [AI PM QA](./interview/AI-PM-QA.md)
- [普通 PM QA](./interview/普通-PM-QA.md)
- [结构化思考训练](./interview/结构化思考训练.md)
- [Agent 与 Workflow 思考训练](./interview/思考训练-Agent与Workflow.md)

不再存放工程冲刺表、项目状态或尚未训练的题库。

### `jz-product/`：公司材料与 AI 辅助稿

保存公司已有 PRD、架构设计，以及 AI 辅助生成的 PRD 和方案。这一层提供参考和事实线索；其中的内容仍需通过公司材料、代码或真实 Case 核验。

### `projects/`：我自己写下的项目沉淀

只保存自己理解、判断、撰写并验证过的内容，包括自己的 PRD、项目复盘、个人贡献、证据和讲述方式。可以引用 `jz-product/`，但不能直接复制其正文或把 AI 结论当成自己的判断。

## 三条规则

1. 公司 PRD 和 AI 辅助稿放在 `jz-product/`；
2. 自己独立写的 PRD 和项目沉淀放在 `projects/`；
3. QA 只有实际回答并点评后才进入 `interview/`。
