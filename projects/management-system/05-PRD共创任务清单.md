# Management-System PRD 共创任务清单

## 共创目标

参考《售前技术顾问（Agent）》PRD 的结构，独立完成工程知识问答助手 PRD，并在过程中学习问题定义、解决方案、用户故事、AI 能力、评测、风险和路线图的写法。

## 共创方式

1. 每次只完成一个 PRD 小节；
2. 先由本人回答或撰写初稿；
3. AI 只做质疑、点评和结构指导；
4. 本人完成重写并确认后，再更新正式 PRD；
5. 区分历史钉钉知识助手、自建 RAG 当前能力和后续规划。

## 已确认内容

- [x] 核心用户：参与 AGV 部署实施的国内外工程团队；外包用户的账号与权限后续单独设计；
- [x] 产品形态：MVP 提供独立、只读的知识问答服务，后续再集成到公司自研的机器人操作软件；
- [x] 知识范围：首期使用研发共享知识库中的文本和表格，暂不支持图片理解与问答；
- [x] 产品边界：不连接车辆实时状态、不读取现场日志、不执行命令、不修改车辆配置；
- [x] 四类产品场景：
  1. 产品信息、指令与规则查询；
  2. 作业流程与配置文档查询；
  3. 文档知识检索与综合问答；
  4. 错误码与故障排查指导；
- [x] 典型 Bad Case：“如何在模板中修改宽度”存在对象歧义，需要通过补充问答确认上下文后再检索；
- [x] 交互原则：以单轮问答为主，问题描述不清或上下文不足时进行追问；回答必须提供知识来源，材料不足时不猜测。
