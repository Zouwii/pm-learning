# AGV 技术支持诊断 Agent：项目问答

> 本文档用于集中沉淀简历4中 Diagnosis-Agent 项目的面试问题与口述答案。后续一次整理一题，保持项目背景、个人职责、方案、指标和结果口径一致。

## 使用规则

1. 每道题先保留问题，再整理可直接口述的答案；
2. 回答优先讲产品判断、个人行动和业务结果，不堆砌技术名词；
3. 区分个人主责、团队协作和底层研发实现；
4. 指标注明分母、样本范围和统计边界；
5. 不把模块归属收敛表述为完成 Bug 修复；
6. 不确定或尚未核验的信息标记为待确认，不临时编造。

## 项目统一口径

- 项目定位：面向 AGV 应用工程师的技术支持诊断 Agent；
- 首期范围：错误码诊断＋高频故障诊断；
- 产品机制：Agent 负责问题理解和路径选择，Workflow 负责标准执行和证据留存，人工负责复核与兜底；
- 知识建设：150 篇错误码排查文档、10 套高频诊断流程；
- 评测范围：从首期目标场景中筛选 50 个真实 Case；
- 核心结果：模块归属收敛率 80%，已收敛 Case 判断准确率 92.5%，简历概括为 92%；
- 效率结果：典型软件故障初筛和模块转交时间由约 60 分钟缩短至约 10 分钟；
- 边界：季度节省约 95 小时为外推测算值；诊断收敛不等于 Bug 已修复。
