# Projects：个人项目沉淀

项目日常完善只打开：[01-项目完善](../01-项目完善.md)。每天完成第一个未勾选任务。

## 目录定位

这里只保存自己理解、判断、撰写并验证过的项目内容。现有 AI 辅助稿会通过 `01-项目完善.md` 逐步重写和核验，不能直接视为个人产出。

它回答的是：

- 这个项目解决了什么问题；
- 我在其中负责什么；
- 我做了哪些关键决策和行动；
- 有哪些可验证结果与事实边界；
- interview 中如何用 30 秒、2 分钟或 5 分钟讲清楚。

## 与 `jz-product/` 的边界

公司 PRD、架构和 AI 辅助稿保存在 `jz-product/`。项目目录可以引用这些材料，但不复制正文；自己的 PRD 必须先独立撰写，再对照参考材料查漏。

`projects/` 可以保存：

- 自己独立撰写的 PRD；
- 个人工作证据；
- 项目复盘；
- 决策与事实边界；
- 讲述版本；
- 指向源代码、实验和 PRD 的证据入口。
