# C++ 与工程能力地图

> 目的不是罗列关键词，而是回答：“我是否在真实工程中用过，证据是什么，面试能否讲清楚？”

## 分级

- **A：可主讲**——有项目、代码、决策和问题处理证据；
- **B：用过**——有实际代码，但需要补充原理或讲述；
- **C：学过**——缺少真实项目证据；
- **D：待补**——目标岗位需要，但目前没有把握。

## 需要单独复习的 C++ 基础

这些内容不能仅凭项目经历默认掌握，后续应根据目标岗位 JD 排优先级：

- 对象生命周期、RAII、移动语义和智能指针；
- 容器、迭代器、算法与复杂度；
- 多态、虚函数、模板及常见语言陷阱；
- 线程、锁、条件变量、原子操作与内存模型；
- CMake、链接、动态库、调试与 core dump；
- Linux 进程、线程、文件、网络和常用排障工具；
- 测试设计、接口隔离与可维护性重构。

## 能力升级原则

1. 先用现有代码恢复真实能力，再刷通用题；
2. 每个 A/B 级能力至少准备一个具体代码点和一个问题 Case；
3. 理论复习必须能回扣项目，不只背定义；
4. 无法证明的能力不放进简历核心区。
